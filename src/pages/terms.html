1. Acceptance of these terms

By using the RenderFrost SMP website, you agree to these terms. If you do not agree with them, please stop using the site. These terms do not require you to create an account, and they do not form a contract to play on the Minecraft server.

2. What this website is

This is an informational website about RenderFrost SMP, a whitelisted Minecraft Java Edition survival community. It publishes the server address, the community rules, membership information, and links to the Discord server.

It is a static website with no backend. It has no accounts, no login, no payments, no subscriptions, no private messaging, and no system that can change anything on the Minecraft server. Where these terms describe a limitation, it reflects how the site is genuinely built rather than a preference.

4. Using the website's features

The interactive features on this site are limited and plain: navigation, the rules contents, the FAQ, the Copy IP button, and the optional soundtrack control.

  • Copy IP copies play.renderfrost.com to your clipboard. Copying an address does not connect you to anything.
  • The soundtrack is optional and only plays when you press play. Your volume and mute choices are stored in your own browser. No music starts automatically.
  • External links, such as the Discord invite, open in a new tab and are marked as leaving this site.

5. Minecraft server access and whitelist

RenderFrost SMP is a whitelisted server. Only authorised staff members can add a player to the whitelist, and every addition is subject to staff verification and approval.

This website cannot grant, check, or restore server access. It has no connection to the server, so it cannot tell you whether you are whitelisted, which version is currently supported, or whether the server is running. Those matters belong to the staff team, reachable through Discord.

Do not treat knowing the address, or receiving a personal invitation from another player, as authorisation to join.
