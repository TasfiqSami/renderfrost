# Cookie Policy.

This policy describes the browser storage used by this static website.

## Cookies

The RenderFrost SMP website does not set cookies. It does not use advertising,
analytics, or cross-site tracking cookies, and it does not load third-party
scripts.

## Local browser storage

If browser storage is available, the optional soundtrack control saves its
volume and mute preference in `localStorage` on your device under
the key `rf.music`. This preference is not a cookie, is not sent to
the website, and is not associated with an account. You can remove it using
your browser's site-data settings. Blocking storage does not prevent the site
from working.

## Hosting requests

Your browser must request the page and its assets from the website host. The
hosting provider may process technical request data in its server logs under
its own policies. See the [Privacy Policy](https://www.renderfrost.com/privacy) for more
information.

## Changes and contact

If the website begins using cookies or other non-essential tracking, this
policy will be updated before describing that use. Questions can be raised
with the RenderFrost staff team through [Discord](https://www.renderfrost.com/discord).
